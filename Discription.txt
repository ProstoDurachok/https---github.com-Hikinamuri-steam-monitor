# Документация для Telegram-бота "Steam Screener" для CS2

Этот документ предназначен для разработчиков, которые будут поддерживать или расширять бот. Он описывает, что реализовано, как это работает, архитектуру, установку, использование и рекомендации по дальнейшей разработке.

## 1. Введение

### Что делает бот?
Бот — это скринер рынка Steam для предметов из CS2 (Counter-Strike 2). Он мониторит цены на скины, оружие, стикеры и другие предметы, анализирует их волатильность (изменчивость цены) и рост объёма продаж. Основные функции:
- Поиск и анализ конкретных предметов по запросу пользователя (`/check`).
- Сканирование рынка по фильтрам и критериям (`/scan`), с выводом результатов сначала в чат пользователя, а затем (по выбору) в канал.
- Автоматический ежедневный скан по расписанию.
- Генерация графиков: изменения цены, объёма продаж, гистограммы ордеров.
- Публикация результатов в Telegram-канал с кнопкой для подтверждения.

Бот ориентирован на пользователей, интересующихся торговлей на Steam Market, и помогает выявлять предметы с высоким потенциалом (высокая волатильность и рост объёма).

### Цели проекта
- Автоматизировать мониторинг рынка CS2.
- Предоставить удобный интерфейс для фильтрации и анализа.
- Обеспечить безопасность (использование прокси, куки, задержек для обхода лимитов Steam API).
- Хранение данных в локальной БД для кэширования и истории.

## 2. Функциональность

### Основные команды бота
- **/start**: Меню с кнопками (настройки, проверка предмета, скан рынка).
- **/set <волатильность> <рост_объема>**: Установка критериев (например, `/set 10 15` для волатильности ≥10% и роста объёма ≥15%).
- **/check <запрос>**: Проверка конкретного предмета (например, `/check USP-S Redline`). Если вариантов несколько, предлагает выбор. Выводит анализ, графики и кнопку для публикации в канал.
- **/scan**: Интерактивный скан рынка:
  - Запрашивает количество предметов.
  - Фильтры: тип, подкатегория, экстерьер, набор, редкость, качество (из FACETS).
  - Ключевые слова (опционально).
  - Выводит результаты в чат пользователя с кнопкой "Опубликовать в канал" для каждого.
- **/settings**: Показ текущих настроек (волатильность, рост объёма, расписание).

### Анализ предмета
- Получает данные о цене, объёме, истории цен из Steam API.
- Рассчитывает:
  - Волатильность: стандартное отклонение цены / средняя цена * 100 (за 7 дней).
  - Рост цены и объёма за 24 часа.
  - Количество публикаций (продаж) за сутки.
  - Ордера на покупку/продажу.
- Генерирует графики (matplotlib): цена, объём, гистограмма ордеров.

### Фильтры в скане
- Использует FACETS для категорий (тип оружия, экстерьер, редкость и т.д.).
- Фильтрует предметы по критериям волатильности и роста объёма из настроек.

### Автоматический скан
- Ежедневно по расписанию (по умолчанию 09:00) сканирует рынок и публикует в канал (если найдены предметы, соответствующие критериям).

### Публикация
- Результаты отправляются как медиагруппа (изображение + графики) с одной подписью.
- Для скана — сначала в личный чат с кнопкой публикации, затем (по клику) в канал.

## 3. Архитектура и реализация

### Технологии
- **Язык**: Python 3 (asyncio для асинхронности).
- **Фреймворк**: aiogram (Telegram Bot API).
- **БД**: SQLite (таблицы: settings, items, price_history).
- **Данные**: Steam Community Market API (priceoverview, pricehistory, itemordershistogram).
- **Анализ**: pandas, numpy для данных; matplotlib для графиков.
- **Дополнительно**: aiohttp для HTTP-запросов, BeautifulSoup для парсинга, dotenv для конфигурации.

### Структура кода
- **Конфигурация**: Загружается из .env (BOT_TOKEN, STEAM_COOKIE, PROXIES и т.д.).
- **БД**: init_db() создаёт таблицы. get_settings(), set_settings() для настроек; save_item(), save_price_history() для данных.
- **FSM (Finite State Machine)**: aiogram FSM для многошаговых диалогов (/check, /scan).
- **API-интеграция**:
  - search_market_items(): Поиск предметов с фильтрами.
  - process_item(): Анализ одного предмета (цена, история, гистограмма).
  - analyze_dataframe(): Расчёт метрик (волатильность, рост).
- **Графики**: plot_price_week(), plot_volume_week(), plot_orders_histogram() — возвращают BytesIO с PNG.
- **Публикация**: publish_item() — собирает медиагруппу, отправляет через bot.send_media_group().
- **Scheduler**: daily_scheduler_loop() — асинхронный цикл для ежедневного скана.
- **Безопасность**: Прокси, ротация куки, задержки (REQUEST_DELAY), семафор для concurrency.

### Ключевые функции
- **scan_and_select()**: Сканирует предметы, фильтрует по критериям, возвращает список подходящих.
- **publish_item()**: Отправляет анализ как медиагруппу. with_publish_button добавляет кнопку публикации.
- **cb_publish_to_channel()**: Обработчик кнопки — публикует в канал без кнопки.
- **perform_scan()**: Логика /scan — выполняет скан, выводит в чат с кнопками.

### Ошибки и обработка
- Логи в steam_screener.log.
- Retry для API-запросов (MAX_RETRIES, RETRY_429_DELAY для 429).
- Кэш (_cache) для поиска предметов.

## 4. Установка и запуск

### Требования
- Python 3.8+.
- Библиотеки: pip install aiogram aiohttp pandas numpy matplotlib beautifulsoup4 python-dotenv sqlite3 pytz.

### Настройка
1. Создайте .env с переменными (BOT_TOKEN, STEAM_COOKIE, PROXIES и т.д.).
2. Запустите бот: python bot.py.
3. Для теста: Telegram-клиент, /start.

### Развёртывание
- Хостинг: VPS (Heroku, AWS) с asyncio.
- БД: SQLite (для продакшена — PostgreSQL).
- Scheduler: Работает в фоне.

## 5. Использование

- Запустите бота, используйте команды.
- Для скана: Выберите фильтры, введите ключевые слова.
- Результаты: Анализ + графики + кнопка публикации.

## 6. Разработка и поддержка

### Как внести изменения
- **Добавление фильтров**: Обновите FACETS, добавьте в build_filter_keyboard и FSM.
- **Новые метрики**: Модифицируйте analyze_dataframe().
- **API-ошибки**: Увеличьте задержки или прокси.
- **Тестирование**: Локально с тестовым ботом. Проверьте логи.

### Известные проблемы
- Steam API-лимиты: Используйте прокси/куки.
- Парсинг: Если Steam изменит HTML, обновите get_nameid_and_russian_name().
- Графики: Убедитесь в шрифтах для русского текста.
